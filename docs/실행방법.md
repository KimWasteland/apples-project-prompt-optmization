# 코드 구조와 실행 방법

코드는 연구 순서대로 버전 폴더에 들어 있다. 버전 폴더마다 필요한 코드가 모두 있어서 다른 폴더의 코드를 불러오지 않는다.
개발 과정과 결과 해석은 `연구일지.md`.

| 연구 순서 | 연구일지 | 코드 | 결과 |
| :--- | :--- | :--- | :--- |
| 1. v2 평가 | 1장 | `prompt-optimizer-v2/eval/evaluate.py` | `results/v2/` |
| 2. v3 설계 실험 | 2장 | `prompt-optimizer-v3/eval/experiments.py` | `results/v3/experiments/` |
| 3. v3 데이터, 학습 | 3장 | `prompt-optimizer-v3/data/build_data.py`, `prompt-optimizer-v3/train.py` | `prompt-optimizer-v3/` |
| 4. v3 평가 | 4장 | `prompt-optimizer-v3/eval/evaluate.py` | `results/v3/` |
| 5. v4 데이터, 학습 | 4장 | `prompt-optimizer-v4/data/build_data.py`, `prompt-optimizer-v4/train.py` | `prompt-optimizer-v4/` |
| 6. v4 평가 | 5장 | `prompt-optimizer-v4/eval/evaluate.py` | `results/v4/` |

## 폴더

```
버전 폴더는 모두 같은 모양이다.
  utils.py             그 버전의 스크립트가 같이 쓰는 코드 (경로, 파일 읽기/쓰기, 통계, 표, GPT/Ollama/보상 모델 호출)
  optimizer.py         모델 추론 (v2는 inference.py)
  train.py             학습
  data/                학습 데이터와 데이터를 만드는 코드
  eval/                평가 코드 (evaluate.py, KoMT 채점을 실행하는 komt_judge.py)

prompt-optimizer-v2/
  inference.py, train.py, app/   v2 원래 코드
  utils.py
  data/dataset.jsonl   v2 학습 데이터
  eval/evaluate.py     v2 평가

prompt-optimizer-v3/
  utils.py, optimizer.py, train.py
  lora_adapter/        직접 학습하면 생기는 어댑터
  test_samples.txt     학습 직후 확인한 생성 예시
  data/
    build_data.py      데이터 만들기 (질문 생성, 정답 작성, 보상 모델로 거르기)
    dataset_v3.jsonl   최종 학습 데이터
    build/             데이터를 만드는 중간 결과 (jsonl)
  eval/
    experiments.py     설계 실험 (섹션 제거 실험, 구조화 실험)
    evaluate.py        v3 평가 (WildChat 평가 문항 선정 포함)

prompt-optimizer-v4/
  utils.py, optimizer.py (v4 규칙 gate, faithful 포함), train.py
  lora_adapter/        직접 학습하면 생기는 어댑터
  data/
    build_data.py      데이터 만들기 (질문 생성, 가이드, 다시 쓰기)
    dataset_v4.jsonl   최종 학습 데이터
    build/             데이터를 만드는 중간 결과 (jsonl)
  eval/
    evaluate.py        v4 평가

results/               실행 결과. 연구 단계마다 폴더 하나
  v2/                  test54, komt
  v3/                  experiments(설계 실험), wildchat_questions(문항 선정), test54, komt, wildchat, ifeval
  v4/                  test54, komt, wildchat, ifeval

  버전 폴더 안의 평가 세트 폴더
    test54/              v2 test 54문항
    komt/                KoMT-Bench 80문항
    wildchat/            WildChat 300문항
    ifeval/              IFEval-Ko 342문항
    experiments/         v3 설계 실험 (섹션 제거, 구조화)
    wildchat_questions/  v3에만 있음. WildChat 평가 문항 선정 (v4도 이 문항을 쓴다)
      candidates.jsonl   규칙으로 거른 후보 1,525개
      gpt_labels.jsonl   후보를 gpt-4o-mini로 분류한 결과
      questions.jsonl    최종 평가 문항 300개

  평가 세트 폴더 안의 파일
    optimized_prompts        최적화된 프롬프트
    optimized_answers        최적화 프롬프트로 받은 답
    optimized_reward_scores  그 답의 보상 모델 점수
    gpt_judgments            GPT 채점 (komt gpt-4o, wildchat gpt-4o-mini 1:1)
    checker_scores           IFEval-Ko 공식 규칙 채점
    original_*               원문으로 받은 답과 점수 (비교 기준). 버전 폴더마다 같은 파일을 복사해 뒀다
    variant_prompts          experiments만. 실험별로 바꾼 프롬프트

  예: v4/wildchat/optimized_answers.jsonl   v4 프롬프트로 받은 WildChat 답
      v4/wildchat/original_answers.jsonl    원문으로 받은 WildChat 답

docs/                  문서 (md)
  연구일지.md, 실행방법.md
  결과표는 report 명령을 실행하면 docs/결과_*.md로 만들어진다

benchmarks/            평가 벤치마크 공식 코드와 데이터 (KoMT-Bench, IFEval-Ko)
```

## 실행 순서

모든 명령은 저장소 루트에서 실행한다. GPT를 쓰는 단계는 `OPENAI_API_KEY`가, 모델을 올리는 단계는 GPU가 필요하다.
이미 결과가 있는 문항은 건너뛰므로, 중간에 끊겨도 같은 명령을 다시 실행하면 이어서 한다.

### 1. v2 평가

```
python prompt-optimizer-v2/eval/evaluate.py prompts      # GPU
python prompt-optimizer-v2/eval/evaluate.py answers      # Ollama
python prompt-optimizer-v2/eval/evaluate.py reward       # GPU
python prompt-optimizer-v2/eval/evaluate.py komt-judge   # GPT
python prompt-optimizer-v2/eval/evaluate.py report       # -> docs/결과_v2.md
```

### 2. v3 설계 실험

```
python prompt-optimizer-v3/eval/experiments.py prompts   # GPU
python prompt-optimizer-v3/eval/experiments.py gpt       # GPT
python prompt-optimizer-v3/eval/experiments.py answer    # Ollama
python prompt-optimizer-v3/eval/experiments.py score     # GPU
python prompt-optimizer-v3/eval/experiments.py report    # -> docs/결과_설계실험.md
```

### 3. v3 데이터, 학습

```
python prompt-optimizer-v3/data/build_data.py inputs      # GPT
python prompt-optimizer-v3/data/build_data.py outputs     # GPT
python prompt-optimizer-v3/data/build_data.py assemble
python prompt-optimizer-v3/data/build_data.py answer      # Ollama
python prompt-optimizer-v3/data/build_data.py score       # GPU
python prompt-optimizer-v3/data/build_data.py filter      # -> data/dataset_v3.jsonl
python prompt-optimizer-v3/train.py                  # -> prompt-optimizer-v3/lora_adapter/
```

### 4. v3 평가

```
python prompt-optimizer-v3/eval/evaluate.py select-questions   # GPT, WildChat 300 선정 (처음 한 번)
python prompt-optimizer-v3/eval/evaluate.py prompts            # GPU
python prompt-optimizer-v3/eval/evaluate.py answers            # Ollama
python prompt-optimizer-v3/eval/evaluate.py reward             # GPU
python prompt-optimizer-v3/eval/evaluate.py wildchat-judge     # GPT
python prompt-optimizer-v3/eval/evaluate.py komt-judge         # GPT
python prompt-optimizer-v3/eval/evaluate.py ifeval
python prompt-optimizer-v3/eval/evaluate.py report             # -> docs/결과_v3.md
```

### 5. v4 데이터, 학습

```
python prompt-optimizer-v4/data/build_data.py inputs      # GPT
python prompt-optimizer-v4/data/build_data.py guides      # GPT
python prompt-optimizer-v4/data/build_data.py rewrite     # GPT
python prompt-optimizer-v4/data/build_data.py assemble    # -> data/dataset_v4.jsonl
python prompt-optimizer-v4/train.py                  # -> prompt-optimizer-v4/lora_adapter/
```

### 6. v4 평가

```
python prompt-optimizer-v4/eval/evaluate.py prompts            # GPU
python prompt-optimizer-v4/eval/evaluate.py answers            # Ollama
python prompt-optimizer-v4/eval/evaluate.py reward             # GPU
python prompt-optimizer-v4/eval/evaluate.py wildchat-judge     # GPT
python prompt-optimizer-v4/eval/evaluate.py komt-judge         # GPT
python prompt-optimizer-v4/eval/evaluate.py ifeval
python prompt-optimizer-v4/eval/evaluate.py report             # -> docs/결과_v4.md
```
