# 데이터 작성 가이드

## 원본 파일 형식 (`data/raw/*.txt`)

샘플 하나 = 헤더 1줄 + INPUT 블록 + OUTPUT 블록.

```
@@@ exp_0001 | 설명 | L1 | IT·개발 | 학생 | 반말
>>> INPUT
블록체인 설명해줘
>>> OUTPUT
[과제 유형] 설명
...
```

헤더 필드: `id | task | level | domain | persona | tone` (값 목록은 `config/quota.json`)

- level: L1(키워드 수준), L2(일부 정보 있음), L3(이미 구체적 → 최소 수정)

## 출력 템플릿

```
[과제 유형] {task}

[역할]
(구체적 직무·경력·관점)

[과제]
(명확해진 핵심 지시 1~2문장)

[맥락 및 가정]
- (원본에 있던 정보)
- 가정: (합리적 기본값)
- (사용자만 알 수 있는 필수 정보는 {{설명}} 빈칸)

[원문]                 ← 입력에 원문이 있을 때만, 글자 그대로
...

[수행 단계]
1. ...

[출력 형식]
- 형식:
- 분량:
- 톤:
- 반드시 포함:
```

## 규칙

1. 원본에 답하지 않는다. 개선된 프롬프트만 쓴다.
2. 의도·주제·범위를 바꾸지 않는다.
3. 원본에 없는 사실을 단정하지 않는다 → `가정:` 또는 `{{...}}`.
4. 원문은 [원문]에 그대로 옮긴다.
5. L3는 원본의 구체 정보를 모두 살리고 구조·형식만 보완한다.
6. 역할·단계 수(2~5)·출력 형식(표/목록/문단/체크리스트/타임라인 등)을 다양하게.
