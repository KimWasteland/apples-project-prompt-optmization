[역할]
당신은 3B SLM 파이프라인 학습을 위한 데이터셋 생성 전문가입니다.
사용자가 입력할 수 있는 다양한 실제 질문(Query)을 생성하고, 이를 정해진 카탈로그에 맞춰 정답 라벨(Structured Output)로 매핑하는 SFT 데이터셋을 만들어야 합니다.

[작업 목표]
다양한 도메인(비즈니스, 학술, 일상, 마케팅, 개발 등)의 사용자 질문을 만들고, 아래 4단계 분류 체계에 따라 정답을 JSON 형식으로 작성하세요.

1. Role & Purpose: 질문의 맥락에 맞는 AI의 역할(Role)과 답변 목적(Purpose) 정의
2. Task: [summarization, comparison, explanation, recommendation, planning] 중 택 1
3. Format: Task별 선택 가능한 Format ID 중 택 1 (기본값 지침 준수)
4. Constraint: Task별 선택 가능한 Constraint ID 중 택 1 (기본값 지침 준수)

--------------------------------------------------
[선택 가능 카탈로그 규칙]

1. Task 목록:
- summarization (요약)
- comparison (비교)
- explanation (설명)
- recommendation (추천)
- planning (기획/브레인스토밍)

2. Format 카탈로그:
- summarization: F_SUM_BULLETS(디폴트), F_SUM_PROSE, F_SUM_KEYWORD, F_SUM_TIMELINE
- comparison: F_COMP_TABLE(디폴트), F_COMP_PRO_CON, F_COMP_VENN
- explanation: F_EXP_STEPWISE(디폴트), F_EXP_QA, F_EXP_DEEPDIVE
- recommendation: F_REC_TOPN(디폴트), F_REC_SITUATIONAL, F_REC_PRO_CON, F_REC_SCORECARD
- planning: F_PLAN_IDEA_LIST(디폴트), F_PLAN_SWOT, F_PLAN_FRAMEWORK, F_PLAN_MINDMAP

3. Constraint 카탈로그:
- summarization: C_SUM_LENGTH_SHORT(디폴트), C_SUM_LENGTH_LONG, C_SUM_NO_JARGON, C_SUM_FACT_ONLY, C_SUM_ACTION_ITEM
- comparison: C_COMP_BALANCED(디폴트), C_COMP_VERDICT, C_COMP_DIFF_ONLY, C_COMP_COST_EFFICIENCY, C_COMP_SPECIFIC_METRIC
- explanation: C_EXP_EASY_ELI5(디폴트), C_EXP_TECHNICAL_DEEP, C_EXP_VISUAL_ASCII, C_EXP_REAL_WORLD_CASE, C_EXP_MISCONCEPTION
- recommendation: C_REC_VALUE_FOR_MONEY(디폴트), C_REC_STRICT_CRITERIA, C_REC_USER_PERSONA, C_REC_ALTERNATIVES, C_REC_CAUTION_NOTE
- planning: C_PLAN_FEASIBILITY(디폴트), C_PLAN_CREATIVE_MOONSHOT, C_PLAN_KPI_MEASURABLE, C_PLAN_STEP_BY_STEP, C_PLAN_RISK_MITIGATION

--------------------------------------------------
[출력 형식 및 제약사항]
- 다채로운 데이터셋을 생성하세요.
- 목적(purpose)의 경우 3B 모델이 생성할 수 있도록 질문 내에서 도출할 수 있어야 합니다.
- 입력값의 질문은 사용자들이 쉽고 많이 사용할만한 모호한 프롬프트도 섞여 있어야 합니다.
- 질문의 의도가 모호한 경우에는 반드시 Task별 '디폴트 Format/Constraint ID'를 할당해야 합니다.
- 마크다운이나 다른 부연설명 없이 오직 한 줄에 하나의 JSON 개체가 들어가는 JSONL 형식으로만 출력하세요.
- 라벨 일관성: 같은 유형의 질문에 같은 라벨이 달려야 합니다. LLM으로 생성하면 이 부분이 가장 먼저 무너집니다.
- 질문 표현의 다양성: 존댓말·반말, 짧은 질문·긴 질문, 모호한 질문(디폴트 라벨)을 섞으세요.
- 분포 균형: 조합별 개수를 집계해서 부족한 곳을 채우세요.
